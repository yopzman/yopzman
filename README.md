## 🚀 About Me

- 🐳 **Containerization Engineer** — designing, building, and operating containerized workloads, from single Docker hosts to production-grade Kubernetes clusters.
- 🖥️ **Virtualisation specialist** — running and tuning hypervisors (Proxmox VE, KVM/QEMU, VMware) for high availability, live migration, and performance.
- 🏗️ **Infrastructure as Code believer** — if it isn't in Git, it doesn't exist. Terraform, Ansible, and GitOps all the way down.
- 📊 **Observability advocate** — Prometheus, Grafana, and alerts that actually matter.
- 🐧 **Certified Linux nerd** — daily-driving Debian & Arch, contributing to open source whenever I can.
- 🌱 Currently deep-diving into **eBPF**, **NixOS**, and advanced GitOps patterns.

> 💬 *"It works on my machine"* — so I ship the machine. 📦
